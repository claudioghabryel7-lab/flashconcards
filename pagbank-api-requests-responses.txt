--------------------------------------------------------------------------------

-------

--------------------------------------------------------------------------------
3) RESUMO DA INTEGRAÇÃO
--------------------------------------------------------------------------------

- Utilizamos apenas a API de Checkout (criar checkout e redirecionar o comprador).
- Métodos de pagamento: cartão de crédito, cartão de débito, PIX e boleto.
- Notificações de pagamento são recebidas no webhook informado acima.
- Sandbox: integração validada com sucesso.
- Produção: aguardando liberação allowlist da API de Checkout.
